Radial / Design System

Design System

The ESA Ecology components in Radial's skin: the inherited legos, re-pointed to Radial's tokens.

The spoke model

Three token tiers cascade. Primitives (raw color ramps, the spacing and radius scales) never move. Semantic roles (--color-background-brand,--color-border-default, --typography-font-family-sans…) are what components actually read, and and what the Radial theme re-points. Component tokens fine-tune individual parts. Because every esa-* component reads only the semantic layer, overriding that one layer re-skins the entire kit with no forks.
