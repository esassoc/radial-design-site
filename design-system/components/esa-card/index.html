API

PropTypeDefaultDescription
titlestring—Header title. Renders the header band.
metaEsaMetaPair[]—Identifying facts about the record, as { label, value } pairs under the title.
subtitlestring—Deprecated in favour of meta. Still renders.
iconstring—Lucide icon name shown left of the title.
variant'default' | 'outlined' | 'elevated' | 'filled''default'Surface treatment.
headerVariant'default' | 'primary' | 'muted''default'Header band tint.
padding'none' | 'compact' | 'default' | 'spacious''default'Body and header padding scale.
SlotTypeDefaultDescription
defaultslot—Card body.
headerslot—Replaces the title block.
actionsslot—Right-aligned controls in the header band.
footerslot—Bottom band below the body.
